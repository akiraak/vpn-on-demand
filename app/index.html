Setup guide

  1. Install Tailscale and sign in. Get it from tailscale.com/download. This app switches Tailscale's exit node; it doesn't install any VPN driver of its own.
  2. Allow the app's servers in your tailnet policy. Open Access controls and add these two sections (merge them if they already exist). autoApprovers lets each new server become an exit node without manual approval. 
    "tagOwners": {
  "tag:vpn-on-demand": ["autogroup:admin"]
},
"autoApprovers": {
  "exitNode": ["tag:vpn-on-demand"]
}
  3. Create a Tailscale auth key. Open Settings → Keys → Generate auth key. Turn on Reusable and Ephemeral, add the tag tag:vpn-on-demand, and pick an expiration (up to 90 days). Paste it above.
  4. Create a Vultr API key. Sign up at vultr.com and add a payment method. Then open Account → API, enable the API, and under Access Control choose Allow all IPv4 and Allow all IPv6 (while connected, your traffic leaves from the server's address, so a home-IP-only rule would block the app). Paste the key above, then press Test setup.
