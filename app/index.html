    Welcome! Finish these four steps to start. It takes about 10 minutes, once.

    Setup checklist

    Get Tailscale from tailscale.com/download, install it and sign in. This app switches Tailscale's exit node; it doesn't install a VPN driver of its own.

    Open Access controls and add these two sections (merge them if they already exist). autoApprovers lets each new server become an exit node without approving it by hand. 

    "tagOwners": {
  "tag:vpn-on-demand": ["autogroup:admin"]
},
"autoApprovers": {
  "exitNode": ["tag:vpn-on-demand"]
}

    The app can't read your policy, so mark this step yourself when you've saved it.

    Open Settings → Keys → Generate auth key, then:

    • Turn on Reusable and Ephemeral
    • Add the tag tag:vpn-on-demand
    • Pick an expiration (up to 90 days)

    Saved key: …

    Sign up at vultr.com and add a payment method. Then open Account → API, enable the API, and:

    • Under Access Control, choose Allow all IPv4 and Allow all IPv6. While connected, your traffic leaves from the server's address, so a home-IP-only rule would block the app.

    Saved key: …

    Keys are stored in your operating system's credential store (Windows Credential Manager / macOS Keychain), never in a file.

    Auto-disconnect

    Vultr bills every hour the server exists, even when it's idle. You get a notification 10 minutes before.
